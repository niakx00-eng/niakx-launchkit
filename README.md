## Overview

NIAKX LaunchKit is a complete startup launch package: a brand identity system, a ready-to-publish landing page, an investor pitch deck, and a 200-prompt AI collection — all designed together, so a founder can go from a blank folder to a live, on-brand presence in a single afternoon.

Everything in this package is built around one visual identity. The colors, type, and logo in the landing page match the pitch deck, which match the brand guide — no reconciling four disconnected tools or freelancers to get a consistent result.

## Features

- **Complete Brand Kit** — Primary, Light, Dark, Symbol, and Favicon logo files (SVG) plus a full Brand Guide (PDF) covering color, typography, spacing, and correct usage.
- **Ready-to-Publish Landing Page** — a single, self-contained HTML file, styled and structured, that opens directly in a browser or deploys to any static host.
- **Investor-Ready Pitch Deck** — a 20-slide PowerPoint template covering everything from vision and market sizing to the ask, styled to match the brand system.
- **200-Prompt AI Collection** — practical, ready-to-use prompts across marketing, branding, copywriting, sales, product, social media, and business strategy.
- **No build tools required** — every file works straight out of the folder. No dependencies, no accounts, no setup scripts.
- **Lifetime updates** — every license includes free access to future revisions of the package.

## Installation

LaunchKit requires no build process, package manager, or account to get started.

1. **Download and unzip** the LaunchKit package to a folder on your computer. Keep the folder structure intact — files reference each other by relative path.
2. **Read `Quickstart.pdf`** for a full walkthrough of every component, including how to open the landing page and apply the brand kit correctly.
3. **Open `Landing-Page/index.html`** in your browser to preview it locally, or upload it to a static host (Netlify, Vercel, GitHub Pages) to publish it.
4. **Reference `Brand-Kit/NIAKX_Brand_Guide.pdf`** before using any logo file in a customer-facing surface — it covers clearspace, minimum size, color, and typography rules.
