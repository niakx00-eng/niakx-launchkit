# Changelog

All notable changes to the NIAKX brand system and documentation package are documented in this file.

The format follows [Keep a Changelog](https://keepachangelog.com/), and versioning follows [Semantic Versioning](https://semver.org/).

---

## [1.0.0] — 2026

### Added

- **Brand Kit** — initial release of the NIAKX visual identity system:
  - Primary logo (full-color lockup)
  - N Symbol (standalone monogram mark)
  - Light (reversed) logo version for dark surfaces
  - Dark (monochrome) logo version for light surfaces and print
  - Favicon / app icon tile
  - Full color palette (Void Navy, Signal Blue, Ion Cyan, Pure White, Slate Surface, Fog Grey) with usage ratios and accessibility guidance
  - Typography system pairing Space Grotesk (display) and Inter (body/UI)
- **NIAKX Brand Guide** — comprehensive brand documentation covering brand overview and pillars, logo usage rules, color and typography specifications, voice and tone guidelines, and governance.
- **NIAKX Pitch Deck** — 20-slide investor presentation template covering cover, vision, problem, market, solution, product, features, customer, competition, business model, pricing, roadmap, growth, metrics, expansion, AI advantage, future, team, ask, and closing.
- **NIAKX 200-Prompt Collection** — premium AI prompt library across seven categories: Marketing, Branding, Copywriting, Sales, Product, Social Media, and Business Strategy.
- **Documentation** — initial `README.md`, `QUICKSTART.md`, and `LICENSE`.

### Notes

- This is the initial public release of the NIAKX brand and documentation package. Future versions will track changes to individual assets (e.g., logo refinements, new deck sections, prompt collection expansions) under their own entries below.

## Versioning Notes

- **Major** versions (`x.0.0`) indicate a brand system change — new logo direction, color palette revision, or full documentation restructure.
- **Minor** versions (`1.x.0`) indicate additive changes — new prompt categories, new deck slides, or expanded guidance — that don't alter existing brand rules.
- **Patch** versions (`1.0.x`) indicate corrections — typo fixes, broken link repairs, or clarifications that don't change guidance or assets.
